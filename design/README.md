# Design exports

Snapshots of the screens designed in the Wonder file "Document Management System" (page 1, main branch), exported 2026-11-06. Images are previews for reference, not source assets; the canvas is the source of truth.

- `tokens.json`: colour, font and radius tokens.
- `screens/mobile/`: 13 mobile screens (390 px wide): sign in, home, award letters, compliance, templates, template editor, document viewer, tenders, tender detail, bid pack builder, review and export, brand assets, letterheads.
- `screens/mobile-v2/`: 9 mobile screens with the revised 5-tab navigation (Home, Library, Bids, Finance, More): bid pack builder v2, award letters v2, finance home, company assets v2, my signature, add document, more menu, add receipt, invoice builder.
- `screens/desktop/`: 4 desktop screens (1440 px wide): dashboard, dashboard v2, document viewer, bid pack builder. Exported at reduced size.
- `reference/website-home.jpg`: FOZY website home page kept on the canvas as a visual reference, not a product screen.
